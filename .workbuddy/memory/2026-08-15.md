# 2026-08-15 工作日志

## CrewAI + DeepSeek V4 Pro 配置

**需求**：配置 CrewAI（crewAIInc/crewAI），接入 DeepSeek V4 Pro 模型。

**关键结论（长期有效）**：
- CrewAI 1.15.x 要求 Python `>=3.10,<3.14`（**不支持 3.14**）。本机 Homebrew Python 是 3.14.3（太新）、macOS 自带 3.9.6（太老），只有 WorkBuddy 内置 3.13.12 兼容；彻底脱离 WorkBuddy 需 `brew install python@3.13`。
- DeepSeek 旧别名 `deepseek-chat` / `deepseek-reasoner` 已于 2026-07-24 停用，改用 `deepseek-v4-pro`（2026-08-13 GA）。
- 接入写法：`LLM(model="openai/deepseek-v4-pro", base_url="https://api.deepseek.com/v1", api_key=...)`（openai 前缀走 OpenAI 兼容接口）。

**已完成**：
- 项目结构：`config/llm.py`（集中 LLM 配置）、`crews/research_crew.py`（研究员→撰稿人示例）、`main.py`、`scripts/test_connection.py`
- 配置：`.env` / `.env.example` / `.gitignore` / `requirements.txt` / `README.md`
- 项目内 `.venv`（Python 3.13.12）

**验证结果（已完成）**：
- crewai 1.15.16 安装成功；DeepSeek 连接测试通过；完整多智能体流程（研究员→撰稿人）跑通，产出中文短文。

**关键提示（重要，可复用）**：
- 在 WorkBuddy 内运行项目 venv 的 Python/pip 时，需 `env -u PYTHONPATH` 清除 PYTHONPATH；否则 WorkBuddy 注入的 shim（`vendor/shim/sitecustomize.py`）会拦截 pip 的文件删除操作，导致安装失败（`SystemExit: bulk delete guard`）。用户脱离 WorkBuddy 后无此 shim，直接 `source .venv/bin/activate` 即可。
- WorkBuddy 沙箱本地代理（127.0.0.1:55714）网络不稳定，下载大包易超时，需多次重试或加大 `--timeout/--retries`。
