# 鸭鸭日记本 — 素材补充说明

> 本应用已可完整运行，以下素材为**后续待补充项**。每项均标注了位置、用途、当前占位方案与替换方式。素材到位后按「替换方式」操作即可，无需改动业务逻辑。

---

## 1. 幼儿端动画素材（优先级最高）

| 位置 | 用途 | 当前占位 | 建议规格 |
|---|---|---|---|
| `app/frontend/index.html` 开场 | 鸭鸭日记本登场欢迎动画 | CSS `bob` 上下浮动 + 简易 SVG 鸭 | MP4/APNG/GIF，或 Lottie JSON，时长 3-5 秒，透明背景 |
| 对话过程 | 鸭鸭"思考/倾听"状态动画 | 静态 SVG 鸭 | 循环动画（点头/眨眼），1-2 秒循环 |
| 录音中 | 按住说话时的动效 | CSS 波纹 `wave` | 声波动画或麦克风呼吸灯动效 |
| 结束 | 会话结束庆祝动画 | CSS 撒花 `confetti` | 庆祝动画（烟花/礼花/鸭鸭欢呼），3-5 秒 |

**替换方式**：将素材文件放入 `app/frontend/assets/`，在 `index.html` 对应位置用 `<img>`/`<video>`/Lottie 播放器替换当前的 CSS/SVG 占位即可，动画触发时机（开场/录音/结束）已预留。

## 2. 角色形象素材

| 素材 | 当前占位 | 建议 |
|---|---|---|
| 「鸭鸭日记本」主形象 | 内联 SVG 黄色小鸭 | 提供 1 张主形象（PNG 透明底，≥512px），可配 2-3 个表情变体（开心/倾听/鼓励） |
| 幼儿头像 | emoji 🐤 | 每名幼儿可选头像（非必须），在教师端幼儿管理上传 |
| 小鸭头像 | 无（文字名） | 每只小鸭一张照片/插画，教师端小鸭管理上传 |

## 3. 语音相关（当前已可用，可选增强）

| 项 | 当前方案 | 可选增强 | 说明 |
|---|---|---|---|
| 语音识别 ASR | 浏览器 Web Speech API（免费，Chrome/Edge 可用） | 腾讯云/讯飞 ASR（儿童中文识别更佳） | 后端已预留 `ASRProvider` 抽象位置，接入时在前端把音频 POST 到后端新接口即可 |
| 语音合成 TTS | 浏览器 SpeechSynthesis（免费，依赖系统中文语音包） | Edge-TTS（后端合成，音色更统一） | 若需统一可爱音色，可在后端新增 TTS 接口 |

## 4. 界面视觉素材（可选）

| 素材 | 说明 |
|---|---|
| 背景装饰 | 幼儿端可加草地/池塘/云朵等童趣背景插画（当前为纯色） |
| 教师端 Logo | 侧边栏当前用 emoji 🦆，可替换为正式 Logo 图 |

## 5. 使用数据（部署时录入，非素材）

以下内容由教师在应用内录入，无需开发：
- 幼儿名单（全名 + 小名）与人数（约 20+ 人）
- 小鸭名单与数量、各自状态
- 值日周期与排班安排

---

**优先级建议**：先补充第 1 项（幼儿端动画）与第 2 项（鸭鸭主形象），这是幼儿端体验提升最明显的部分；语音增强（第 3 项）可在使用中观察识别效果后再决定。
