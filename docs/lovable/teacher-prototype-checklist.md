# Lovable 教师端原型评审清单

视觉参考，不连接鸭鸭日记本后端

## 范围与数据安全

- [ ] 只生成两个桌面页面：今日任务工作台和值日审阅工作台。
- [ ] 页面使用固定脱敏 JSON，全部幼儿和小鸭身份均来自允许的虚构名单。
- [ ] 明确标注这是视觉投影，不是应用 API 数据结构。
- [ ] 原型运行时没有数据库、后端、登录、分析、遥测、上传或外部连接。
- [ ] 页面没有要求更多文件、源码、账号、数据源或连接权限。
- [ ] 所有保存、确认、重试和开始对话均明确为本地 mock，不宣称真实写入。

## 今日任务工作台

- [ ] 一级标题为“今日任务”，进入页面后焦点落在该标题。
- [ ] 两条今日排班都重复显示幼儿姓名、昵称、文字头像、小鸭和班次。
- [ ] “开始对话”是每条排班中最清楚的主动作，且说明为本地演示。
- [ ] 待审阅、分析中、分析失败三个区域的层级和状态一眼可区分。
- [ ] 待审阅项可进入对应审阅详情，分析中项不误导为可审阅。
- [ ] 分析失败项显示固定安全文案和单次“重新分析”动作。
- [ ] 每个区域分别具有 loading、empty、failed、retrying 状态，局部失败不遮蔽其他区域。

## 值日审阅工作台

- [ ] 左侧队列持续可见，当前项同时使用文字和视觉标识。
- [ ] 队列、详情标题、原始对话和结构化结果重复同一个幼儿身份。
- [ ] 原始对话严格显示六条消息，并清楚区分“幼儿”和“日记本”。
- [ ] 结构化结果完整显示两条饲养记录、情绪、强度、备注和教育洞察。
- [ ] 能力评估只包含语言表达能力、同理心、勤劳启蒙三个维度。
- [ ] 每个维度的 1 至 5 分选项和评分理由具有清楚、唯一的标签。
- [ ] 页面底部固定保存栏不遮挡内容，包含“保存草稿”和“保存并确认”。
- [ ] confirmed 状态为只读，并显示“审阅已确认”。

## 状态与错误恢复

- [ ] loading 时不闪回旧内容，区域具有明确忙碌状态。
- [ ] empty 状态说明没有任务，并提供返回今日任务的路径。
- [ ] failed 状态显示“加载失败，请重试。”和可操作的重试按钮。
- [ ] retrying 与 saving 状态禁用重复动作，始终保持单飞。
- [ ] dirty 状态离开或切换会话时提供“继续编辑”和“放弃修改”。
- [ ] saved 状态显示“全部修改已保存”，但不改变当前对象身份。
- [ ] revision conflict 保留全部输入并显示“该审阅已在别处更新，请复制当前修改后重新加载。”
- [ ] analysis failed 显示“分析失败，请返回今日任务重试。”及明确返回路径。
- [ ] 保存失败时保留已输入值、恢复全部控件并把焦点移到错误摘要或首个错误字段。

## 键盘与无障碍

- [ ] 所有主要交互目标至少 44px，鼠标、触摸和键盘均可操作。
- [ ] 键盘顺序与视觉顺序一致：导航、队列、详情、表单、固定保存栏。
- [ ] 所有按钮、链接、输入框、单选组都有持续可见焦点。
- [ ] 关闭确认、完成重试或保存失败后执行正确的焦点恢复。
- [ ] 当前导航、当前队列项、加载、错误和保存结果具有文本语义与状态播报。
- [ ] 颜色不是唯一状态提示，图标均有文字名称。
- [ ] 分数单选的可访问名称同时包含维度和分值。

## 视觉层级与响应式

- [ ] 1024×768 下两页的核心任务都可完成，且页面没有水平滚动。
- [ ] 200% 缩放下主要信息、表单和固定保存栏仍可读、可操作。
- [ ] 正文、辅助文字、按钮、焦点环和错误状态达到清楚的对比度。
- [ ] 更宽视口只增加合理留白，不把正文或对话行无限拉长。
- [ ] 幼儿身份、任务状态和下一步动作的层级高于装饰元素。
- [ ] 启用减少动态效果后，非必要弹跳、位移和庆祝动画全部关闭。

- [ ] GO：全部强制项通过，可作为后续样式和交互移植参考。

- [ ] NO-GO：存在数据安全、任务流、错误恢复或无障碍阻断。
- [ ] 已记录未通过项、观察结果、负责人和复查条件。
- [ ] 已确认本清单只评价原型，不替代产品测试、代码审查或上线验收。
