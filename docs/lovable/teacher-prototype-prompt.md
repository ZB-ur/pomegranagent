# 鸭鸭日记本教师端脱敏原型提示词

## 任务边界

只生成两个桌面页面，适配 1024×768 及更宽视口：

1. 今日任务工作台。
2. 值日审阅工作台。

只使用随本提示词附上的脱敏 JSON，把它作为本地 mock 状态。不要添加第三个页面，不做手机端重构，不创建登录流程，不连接数据库、后端或真实 API，不发送运行时网络请求，不加入分析、遥测或上传功能。所有按钮只在页面内模拟状态，不能暗示数据已经写入真实系统。

你粘贴的本提示词和脱敏 JSON 是两份完整输入文档，不接受也不需要其他输入。

这是仅供视觉评审的投影数据，不是鸭鸭日记本 API 数据结构。

不连接 Supabase。

不连接 GitHub。

## 视觉方向

- 气质温暖、可信、克制，适合幼儿园教师日常使用；避免玩具化和过度装饰。
- 优先呈现任务层级、幼儿身份、队列状态和下一步动作，不用大面积渐变或无意义动画抢占注意力。
- 颜色不能成为唯一状态信号；图标同时配文字，正文和控件保持清晰对比度。
- 信息密度适合 1024×768，页面不产生水平滚动；更宽视口增加留白，不无限拉长正文。
- 所有交互目标至少 44px，支持完整键盘操作、可见焦点和焦点恢复。
- 遵循减少动态效果偏好，关闭非必要位移、弹跳和庆祝动画。

## 页面一：今日任务工作台

页面标题为“今日任务”。顶部先显示今日值日生，使用 JSON 中两条排班记录，重复展示幼儿姓名、昵称、文字头像、小鸭和上午或下午班次。每条排班提供清晰的“开始对话”主动作，但仅做本地状态演示。

下方并列或分区展示三个队列：

- “待审阅”：显示已分析完成的草稿会话，主动作进入值日审阅工作台。
- “分析中”：显示进行中的会话和明确进度，不提供审阅动作。
- “分析失败”：显示固定失败提示和“重新分析”动作；重试期间只允许一次请求模拟。

在每个区域分别设计加载、空、失败和重试状态。局部失败只影响当前区域，其他区域继续可用。错误消息使用固定安全文案，不能显示技术细节。主要操作紧邻对应任务，状态文本对读屏软件可播报。

## 页面二：值日审阅工作台

采用“左侧队列 + 右侧详情”的稳定布局。左侧持续显示待审阅队列，当前选中项有文字和视觉双重标识。队列项、详情标题、原始对话和结构化结果中必须重复同一个幼儿身份，避免教师审错对象。

右侧先显示选中幼儿、完成时间、轮次和草稿状态，再用双栏呈现：

- 左栏标题“原始对话”，按时间顺序展示六条消息，清楚区分“幼儿”和“日记本”。
- 右栏标题“结构化结果”，展示两条饲养记录、情绪与强度、情绪备注和教育洞察。

双栏下方是“能力评估”，严格展示三个维度：语言表达能力、同理心、勤劳启蒙。每项包含 1 至 5 分单选和评分理由。饲养记录、情绪、洞察、分数和理由均可在本地 mock 中编辑。

页面底部使用固定保存栏，提供“保存草稿”和“保存并确认”。保存期间两按钮和全部表单控件都禁用，只显示一次进行中反馈；完成后再恢复。确认成功后进入只读状态，并明确显示“审阅已确认”。

## 必须覆盖的交互状态

- `loading`：区域带加载文案和忙碌语义，不能显示旧内容。
- `empty`：说明当前没有任务，并给出返回今日任务的清晰路径。
- `failed`：使用固定安全文案“加载失败，请重试。”并提供 44px 重试按钮。
- `retrying`：重试按钮禁用，避免重复触发，完成后只更新对应区域。
- `dirty`：编辑后离开页面、切换会话或点击当前导航时，提示继续编辑或放弃修改。
- `saving`：固定保存栏显示“正在保存…”，所有编辑控件与保存动作单飞禁用。
- `saved`：显示“全部修改已保存”，随后保持当前会话和修订信息。
- `confirmed`：显示“审阅已确认”，表单只读，待审阅队列移除该项。
- `revision_conflict`：保留全部已输入内容，显示“该审阅已在别处更新，请复制当前修改后重新加载。”，不宣称保存成功。
- `analysis_failed`：显示“分析失败，请返回今日任务重试。”并提供返回路径。
- `reduced_motion`：减少动态效果，只保留必要的淡入或状态切换，不使用位移动画。

## 交互与无障碍要求

- 键盘顺序与视觉顺序一致：全局导航、队列、详情、表单、固定保存栏。
- 每次进入页面后将焦点放到一级标题；关闭确认框、完成重试或保存失败后恢复到触发控件或首个错误字段。
- 当前导航、当前队列项、错误、加载和保存结果具有可读的语义标签与状态播报。
- 不用占位文字代替标签；单选分数的可访问名称包含维度和分值。
- 在 200% 缩放和 1024×768 下保持主要任务可完成、固定保存栏不遮挡内容、页面无水平滚动。
- 先实现清楚的状态与任务流，再处理阴影、圆角和微动效。

## 输出要求

交付可点击的高保真视觉原型和本地 mock 状态切换，用于评审信息层级、布局、文案、错误恢复与键盘体验。不要生成生产接入说明，不要请求更多文件、账号、数据源或连接权限。
