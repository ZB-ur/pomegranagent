## 关键修复

修复前用户看到的"页面只有一个框架"的根因：

1. **teacher.html `show()` 函数从未把 view 节点 append 到 DOM**——只 `classList.add('active')`，但节点不在文档里，整个右侧主区域全部为空（致命 bug）。
2. 后端首次启动时数据库为空，无种子数据，幼儿端没有可选卡片。
3. 教师端 hash 路由不支持 query 参数（`#growth?child_id=1` 中的 `?child_id=1` 实际属于 hash），URL 参数不生效。

修复：
- teacher.html: `show()` 内 `main.appendChild(views[name])`
- 后端: 新增 `_seed_demo_data()`，首次启动自动插入 5 幼儿 + 3 小鸭 + 14 排班
- teacher.html: hash 路由 `split('?')[0]`；growth 函数兼容 `?child_id=1#growth` 与 `#growth?child_id=1`
